# Echo AEC Free

Android Echo Cancellation integration project for Minecraft Simple Voice Chat.

## Project Goal
Reduce speaker-to-microphone audio echo on supported Android devices.

## Planned Features
- Android Acoustic Echo Canceler integration.
- Preserve existing Noise Suppression behavior.
- Fabric client-side mod.

## Compatibility
- Minecraft 26.2
- Fabric Loader
- Simple Voice Chat

## Development Status
AEC integration is under development and has not yet been tested in-game.
